# 🚀 What This Skill Does

This is not a generic motivational fitness assistant.

The skill is designed as a modular coaching system that:
- Builds personalized training plans
- Generates structured meal strategies
- Evaluates recovery and fatigue
- Tracks performance progression
- Adjusts programming dynamically

The architecture separates responsibilities into specialized agents for better reasoning and reliability.

# ⚙️ Installation

## 1. Clone the Repository

```bash
git clone https://github.com/yourusername/elite-fitness-coach.git
```

---

## 2. Add to Claude Skills Directory

Move the folder into your Claude Skills directory.

Example:

```text
Claude/
└── Skills/
    └── elite-fitness-coach/
```

---

## 3. Restart Claude

Reload Claude so the skill becomes available.
